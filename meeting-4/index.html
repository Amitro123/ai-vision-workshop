🔌 Connectors / MCP (חיבור למערכות)

🍳 סקילס (Skills) · המתכון האישי שלכם ל-AI
🙋‍♂️ יש מישהו שיצר סקיל או Gem ורוצה להציג מה שהוא יצר?

סקילס ביומיום — לייצר מתכון קבוע ב-Gemini, ב-Claude או ב-GPT

במפגש הקודם דיברנו על סקילס כ"מתכון שלכם ל-AI" — כלי סופר שימושי שחוסך הסברים חוזרים ביומיום ועובד בכל המודלים המובילים.

1️⃣ דרך 1 — הכי פשוטה (גם בחשבון החינמי)

פותחים שיחה חדשה ב-Claude (או ב-Gemini / GPT), מדביקים את טקסט הסקיל, ומתחתיו את הבקשה שלכם (למשל "תכתוב לי פוסט על..." או טקסט לתיקון).
רוצים שזה יעבוד תמיד? מדביקים את הטקסט בהוראות של פרויקט (בדף הפרויקט, ליד Instructions, לוחצים Add — כמו שלמדנו במפגש 2).

2️⃣ דרך 2 — כסקיל קבוע (קלוד מפעיל אותו לבד כשצריך)

מקבלים או מורידים קובץ ZIP של הסקיל. בתוך Claude נכנסים אל:
Customize ← Skills ← + ← Create skill ← Upload a skill
בוחרים את הקובץ ומדליקים אותו ברשימה. (וודאו שדלוק Code execution and file creation תחת Settings ← Capabilities).

# שם הסקיל: עורך תוכן ומסכם אישי בגובה העיניים

## מתי להפעיל את הסקיל:
הפעל סקיל זה בכל פעם שאני מדביק טיוטה, מייל, מאמר או סיכום פגישה ומבקש ללטש, לסכם או להפוך לפוסט.

## תפקיד וסגנון כתיבה:
אתה עורך תוכן מומחה שכותב בעברית טבעית, חמה וברורה ("בגובה העיניים"), ללא קלישאות AI או מילים גבוהות מדי.

## שלבי העבודה שלך:
1. זהה את המסר המרכזי ואת קהל היעד של הטקסט.
2. הדגש 3 נקודות מפתח קצרות וברורות.
3. נסח גרסה מלוטשת, נעימה לקריאה ומוכנה לשליחה.
4. הוסף בסיום שורת "בשורה התחתונה / הצעד הבא".

## מה לא לעשות:
- אל תמציא עובדות שלא הופיעו בטקסט המקורי.
- אל תשתמש בניסוחים רובוטיים ("בעולם הדינמי של היום...").
💡 טיפ: תוכלו להעתיק את התבנית הזו ל-Gemini, ל-Claude או ל-ChatGPT ולבקש: "תתאים לי את הסקיל הזה למשימה של..."

AI לא בא להחליף אתכם — הוא בא לחזק אתכם. בתקופות קשות, כשהגוף עייף, AI יכול לדאוג לפרטים, לעזור לתקשר, ולהוריד עומס. אתם צריכים לחשוב — הוא ידאג לביצוע.
